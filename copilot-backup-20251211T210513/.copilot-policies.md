## Service Architecture

### Frontend Routing
- All frontend traffic **MUST** route through gateway (port 8080)
- Backend should only see localhost requests from gateway
- CORS handled at gateway level, not backend

### Authentication Flow
- Login works on both web and Android
- JWT tokens persist across page navigation
- Auth state must propagate before making authenticated requests
- Avoid race conditions by not auto-loading data in component init

### Service Endpoints
- Backend: localhost:8081 (internal only)
- Gateway: localhost:8080 (public facing)
- Web frontend: served via gateway as static assets
- MindsDB integration: chatbot tries MindsDB first, falls back to OpenAI/mock
