# Droid Client (React Native)

Minimal React Native app for Android, replacing ai-catalog.

## Features
- Home/services page
- Top-right hamburger menu
- Login modal placeholder
- Cityscape background (`assets/cityscape.png`)

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start Metro bundler:
   ```bash
   npm start
   ```
3. Run on Android emulator/device:
   ```bash
   npm run android
   ```

## Notes
- Requires Android SDK and emulator/device.
- Cityscape background is in `assets/cityscape.png`.
